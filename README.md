# Personality Assessment Tool

A web-based psychometric assessment tool based on the **Big Five Aspect Scale** (BFAS) by C. DeYoung, L. C. Quilty, and Jordan B. Peterson.

## Features
- Interactive assessment with Likert scale responses.
- Real-time scoring interaction matrix.
- Detailed personality profile results.
- Responsive design for mobile and desktop.

## How to Run
Simply open `index.html` in your web browser.
